## Scope and migration

This candidate updates the bundled Codex runtime from `0.160.0` to `0.160.1`
(`rust-v0.160.1`, public source commit `d27764b82f7118f674371e6d6e76271d9d606edb`). The
generated public TypeScript protocol, JSON Schema, and method map are unchanged; no public client
API migration is required. Applications upgrading from client versions before `0.3.0` should still
review the removal of `thread/rollback` in the [0.3.0 migration guide](./0.3.0.md).

The client package version is independent of the Codex runtime version. Use an exact published
client version and retain your lockfile. See [compatibility guidance](../../COMPATIBILITY.md) and
the [API reference](../api.md).
