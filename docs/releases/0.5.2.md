# 0.5.2 release guide

Target: `@jaminzhou/codex-app-server-client@0.5.2`, non-preview, intended npm tag `latest`.
This source record alone does not prove the version has been published; check the npm registry for
the exact version and tag state.

```bash
npm view @jaminzhou/codex-app-server-client@0.5.2 version --registry https://registry.npmjs.org/
npm install --save-exact --ignore-scripts --include=optional @jaminzhou/codex-app-server-client@0.5.2
node node_modules/@jaminzhou/codex-app-server-client/examples/stream.mjs
```

## Scope and migration

This patch updates the bundled Codex runtime from `0.159.3` to `0.160.0` (`rust-v0.160.0`) and
allows isolated packaged examples 30 seconds per RPC. Non-interactive mock examples also have a
separate 45-second per-example deadline; interactive examples stay open for user input, and live
turns have no imposed total deadline. The generated public TypeScript protocol remains unchanged
from `0.159.0`; no public client API or generated protocol type changes, so existing integrations
do not require migration. Candidate preparation must pass `pnpm protocol:latest-check` and the
release gates in [`RELEASING.md`](../../RELEASING.md) before publication.

The client package version is independent of the Codex runtime version. Use an exact client version
and retain your lockfile. See [compatibility guidance](../../COMPATIBILITY.md) and the
[API reference](../api.md).
Applications upgrading from client versions before `0.3.0` should also review the removal of
`thread/rollback` in the [0.3.0 migration guide](./0.3.0.md).

## Verification boundaries

Candidate preparation, reviewed merge, OIDC publication, registry read-back, and exact npm/pnpm
consumer checks are separate release stages. Follow the current gates in
[`RELEASING.md`](../../RELEASING.md); neither this guide nor a source version proves publication.
Compatibility and example smoke tests use isolated app-server processes and local fixtures. They do
not establish real-account OAuth, live-account access, or model-quality acceptance.
