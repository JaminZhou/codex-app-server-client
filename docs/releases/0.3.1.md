# 0.3.1 release guide

Target: `@jaminzhou/codex-app-server-client@0.3.1`, non-preview, intended npm tag `latest`.
This source record alone does not prove the version has been published; the npm registry is
authoritative for exact-version availability.

```bash
npm view @jaminzhou/codex-app-server-client@0.3.1 version --registry https://registry.npmjs.org/
npm install --save-exact --ignore-scripts --include=optional @jaminzhou/codex-app-server-client@0.3.1
node node_modules/@jaminzhou/codex-app-server-client/examples/stream.mjs
```

## Scope

This release updates the bundled Codex runtime and generated public app-server protocol from
`0.156.1` to `0.157.1` (`rust-v0.157.1`, public source commit
`36650394c5b38c2990ccf2a3457165ca3e9d9726`). It adds typed mappings for
`account/gatewayOAuth/read`, `account/gatewayOAuth/login`, and `account/gatewayOAuth/cancel`, plus
the `account/gatewayOAuth/changed` notification and generated plugin, hosted-MCP, realtime V3, and
thread-item timestamp types. No existing client method was removed. Fields optional in the upstream
Schema remain optional in TypeScript so older supported app-server versions can omit them.

The client remains pre-1.0. Consumers should pin an exact version and retain the lockfile. The
previous `0.3.0` release removed the upstream-retired `thread/rollback` method; see the
[0.3.0 migration guide](./0.3.0.md) when upgrading from earlier versions.

## Verification boundaries

Candidate preparation, reviewed merge, OIDC publication, registry read-back, and exact npm/pnpm
consumer checks are separate release stages. Follow the current gates in
[`RELEASING.md`](../../RELEASING.md); neither this guide nor a source version proves publication.
Compatibility and example smoke tests use isolated app-server processes and local fixtures. They do
not establish real Gateway OAuth sign-in, live-account access, or model-quality acceptance.
