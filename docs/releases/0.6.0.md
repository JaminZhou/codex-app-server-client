# 0.6.0 source-candidate record

Candidate version: `@jaminzhou/codex-app-server-client@0.6.0`. This is an unpublished source
candidate, not a release; no registry tag or package archive is selected. Check the npm registry
before preparing an exact release archive.

## Scope and migration

This candidate updates the bundled runtime to `@openai/codex@0.162.0`, generated from public tag
`rust-v0.162.0` at commit `c1382380de69521303b416720a52f42d51af6248`. It adds three typed client methods
and 13 protocol type exports. No prior client method or generated type export is removed.

The upstream protocol removes `namespaceTools`; the client retains it as a deprecated optional field
for responses from older supported runtimes. New fields that older app-servers can omit remain
optional in the TypeScript compatibility surface. This update does not add high-level wrappers for
the new raw protocol methods. Consumers upgrading from before client `0.3.0` must still review the
older `thread/rollback` removal documented in the [migration record](./0.3.0.md).
